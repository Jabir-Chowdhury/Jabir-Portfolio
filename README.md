# Jabir Portfolio

A responsive personal portfolio website built with HTML and CSS, featuring modern layouts, smooth animations, and a clean visual design.

## Features

- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
- **Modern UI:** Clean layouts, consistent styling, and well-structured sections.
- **Animations & Transitions:** Enhanced visual interactions and user experience.
- **Portfolio Sections:** Header, Hero, About, Skills, Projects, Resume, Contact, and Footer.
- **CV Download:** Includes a downloadable resume.

## Development Workflow

- Organized project repository and folder structure.
- Managed development tasks using GitHub Projects and a Kanban board.
- Created and tracked 9 issues from start to completion.
- Used Git and GitHub to manage changes and maintain a structured development workflow.
